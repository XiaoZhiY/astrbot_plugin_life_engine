# 生活引擎 · astrbot_plugin_life_engine

让 Bot 有**自己的日子**，并把这段生活低频注入对话。

每天一次模型调用：结合人设和兴趣，从真实抓来的素材（抖音热榜 / B站热搜 / B站热门 / **游戏区排行** / **番剧排行** / 网易云热歌）里安排今天的计划、时间线和刷到的东西。之后全天不再调用模型——聊到相关话题时，直接把这些内容塞进 system prompt，它就有了"我刚在干嘛"。

因为它看的是**当天的榜**，所以它在玩的游戏、在追的番会跟着真实热点走，不需要你维护任何清单。它还会按你在 `profile.json` 里写的**口味**去搜"最近有什么能开的新坑"，并且把玩过看过的都记进 `library.json`，长期不重复。

## 特性

- **一天一次调用**：08:30 生成，之后靠注入，不额外烧 token
- **素材都是真的**：抖音热榜、B站热搜/热门、B站游戏区排行、B站番剧排行、网易云热歌，模型只能按编号引用，编不出不存在的内容
- **会写具体名字**：素材里出现作品名（游戏、番剧）时，写的就是这个名字，而不是"那个番""某个游戏"
- **追热点**：游戏榜和番剧榜每天都在变，它每天玩什么、追什么也跟着变
- **按口味开新坑**：用 `preferences` 里的口味词去搜本季新番/同类游戏，搜到的候选才允许开新坑
- **长期作品库**：`library.json` 记下每一部玩过/看过的作品，`cooldown_days` 内不会重复开坑
- **短期防重复**：最近几天做过的事不再原样重写；同一部番可以继续，但要有推进
- **可选搜索兜底**：拿番剧榜第一名去 AnySearch 查一次"更新到第几集"，补一条进度细节；**不通就放弃，不重试、不影响生成**
- **作息约束**：时间线只落在 `wake_time` ~ `sleep_time` 之间，深夜不会冒出"正在看电影"
- **只写自己**：时间线里不出现"和用户聊天"这种自我引用
- **低频注入**：默认静默 30 分钟后的第一轮才注入一次，避免每轮都占 token
- **可写日记**：凌晨把当天的事压成一两句写进日记素材（可选，没装日记插件就跳过）
- **幂等 + 重试**：同一天只生成一次；失败按 2 / 5 / 15 分钟退避

## 安装

```bash
cd AstrBot/data/plugins
git clone https://github.com/XiaoZhiY/astrbot_plugin_life_engine.git
```

重启 AstrBot，在插件配置里填 `umo`（会话标识，形如 `qq_official:FriendMessage:DEADBEEF`；不确定就在目标会话发 `/sid`）。

### 改兴趣

第一次运行会生成 `data/plugin_data/life_engine/profile.json`，里面是它的兴趣画像：

```json
{
  "identity": "18 岁，学生，宅，话不多",
  "platforms": ["B站", "抖音", "网易云"],
  "games": ["王者荣耀", "原神", "Steam 独立游戏", "3A 单机"],
  "anime": ["日番", "国创"],
  "preferences": {
    "anime": ["悬疑推理", "日常治愈", "科幻"],
    "games": ["roguelike", "独立解谜", "模拟经营"],
    "avoid": ["后宫", "恐怖", "竞技"]
  },
  "topics": ["猫", "生活区vlog", "美食探店", "番剧吐槽", "游戏攻略"],
  "habits": ["熬夜", "赖床", "半夜饿了找吃的"],
  "avoid": ["出门玩", "和网友私信互动", "线下活动", "见任何人"]
}
```

直接改这个文件，第二天生效。删掉它会按默认值重建。想让它更贴合你的人设，就改 `identity` 和 `topics`。

### 口味怎么填

`preferences` 决定它去搜什么新东西，只写**类型**，不用写具体作品名：

- `anime` 取第一个词去搜「X年Y月新番 一览 那个词 推荐」
- `games` 取第一个词去搜「Steam 那个词 游戏 推荐 X年」
- `avoid` 目前只是提示词里的软约束

搜回来的结果只作为**候选**，模型要开新坑必须从候选里挑，挑完写进 `started`，然后进作品库。

## 配置

| 配置项 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 关闭后不生成、不注入 |
| `persona` | 空 | 读不到会话人设时的备用口吻 |
| `search_enrich` | `true` | 用搜索补一条番剧进度 |
| `search_api_key` | 空 | AnySearch Key，留空走匿名额度 |
| `discover_enabled` | `true` | 按口味搜新坑候选 |
| `discover_per_day` | `2` | 番剧、游戏各算一类，最多 3 类 |
| `cooldown_days` | `60` | 作品库里的作品多少天内不再当新坑 |
| `recent_days` | `3` | 防重复参考最近几天的记录 |
| `generate_hour` / `generate_minute` | `8` / `30` | 每天几点安排今天 |
| `wake_time` / `sleep_time` | `08:30` / `00:30` | 作息，时间线只落在这个区间 |
| `events_min` / `events_max` | `4` / `6` | 时间线条数 |
| `keep_days` | `7` | `life.json` 保留几天 |
| `retry_times` | `3` | 失败重试次数 |
| `umo` | 空 | 哪个会话，**必填** |
| `inject_mode` | `low` | `off` / `low`（推荐）/ `always` |
| `inject_gap_minutes` | `30` | `low` 模式的间隔 |
| `write_to_diary` | `true` | 写进日记素材 |
| `diary_at` | `01:30` | 几点写，必须早于日记插件的整理时间 |
| `diary_sender` | `助手` | 日记里显示的发信人 |

### inject_mode 怎么选

| 模式 | 行为 | 适合 |
|---|---|---|
| `off` | 完全不注入 | 只想要生成的记录，不想影响对话 |
| `low` | 静默超过 `inject_gap_minutes` 后的第一轮注入一次 | 日常聊天，省 token |
| `always` | 每轮都注入 | 强人设场景，token 换连贯性 |

注入的内容长这样，只占几行：

```
【你最近】
今天想做：把《间谍过家家 第三季》新更的看掉、推过卡住的那一关、晚上刷B站
刚发生：边吃早饭边看《间谍过家家 第三季》，看得笑出声
心情：今天有点困，但也不太想动
在追/在玩：间谍过家家 第三季、名侦探柯南、崩坏：星穹铁道
刷到的：浪浪山小妖怪金鸡最佳动画片
```

## 素材从哪来

| 源 | 接口 | 提供什么 |
|---|---|---|
| 抖音热榜 | `aweme/v1/web/hot/search/list` | 今天大家在聊什么 |
| B站热搜 | `x/web-interface/search/square` | 站内热词 |
| B站热门 | `x/web-interface/popular` | 正在火的视频 |
| **B站游戏区排行** | `x/web-interface/ranking/v2?rid=4` | **具体游戏名/版本名** |
| **B站番剧排行** | `pgc/web/rank/list?season_type=1` | **具体番名 + 评分** |
| 网易云热歌 | `api/playlist/detail` | 在听的歌 |
| 搜索兜底（可选） | AnySearch `/v1/search` | 番剧更新进度 |
| **口味发现（可选）** | AnySearch `/v1/search` | **本季新番表 / 同类游戏推荐页** |

所有源并发抓取，任何一路失败都只是少几条素材，不影响生成。

> 关于搜索质量：查询词写得好不好差别极大。实测「悬疑推理、日常治愈 番剧 推荐 新番」这种堆口味词的问法会返回一堆无关法律文书，而「2026年10月新番 一览」这种"找清单页"的问法才拿得到能用的作品名。插件内已经按后者构造查询。

## 工作流程

```
08:30 生成
  ├─ 并发抓素材：抖音热榜 / B站热搜 / B站热门 / 游戏区排行 / 番剧排行 / 网易云
  ├─ 可选：搜一次番剧进度（不通就跳过）
  ├─ 可选：按口味搜新坑候选
  ├─ 读最近 recent_days 天的记录 + 作品库，拼成"别重复"提示
  ├─ 加上兴趣画像和作息，一次模型调用
  ├─ 校验：时间必须在作息区间、条数在范围内、引用编号必须存在
  ├─ 从素材里认出今天写到的作品名，连同 started 一起写进 library.json
  ├─ 存进 life.json（保留 keep_days 天）
  └─ 失败则用内置兜底日程

全天 注入
  └─ on_llm_request 钩子，按 inject_mode 把今天的片段拼进 system prompt

01:30 写日记
  └─ 把当天时间线压成一两句，写进日记插件的素材库
```

## 数据文件

```
AstrBot/data/plugin_data/life_engine/
├── life.json       每天的计划/时间线/刷到的东西（只留 keep_days 天）
├── library.json    长期作品库：玩过/看过的，带类型和首次时间
├── profile.json    兴趣画像 + 口味（可手改）
└── state.json      生成状态，用于幂等
```

`library.json` 长这样，只会增加不会过期，删掉就相当于"失忆"：

```json
{
  "works": {
    "阿尔涅的事件簿": {"type": "anime", "first": "2026-11-11", "last": "2026-11-11", "count": 1},
    "名侦探柯南": {"type": "anime", "first": "2026-11-11", "last": "2026-11-11", "count": 1},
    "绝区零": {"type": "game", "first": "2026-11-11", "last": "2026-11-11", "count": 1}
  }
}
```

- `type`：`anime` / `game` / `?`（认不出来源时）
- `first` / `last`：第一次碰、最近一次碰
- `count`：被写到过几次（可以看它有多偏爱某部）
- 热门视频**不进这个库**——更新太快，记了没意义

## 和"主动消息"类插件的关系

这个插件只负责**生成生活状态**，不负责发消息。想让它拿这段生活当话题主动找你，需要另外的主动消息插件；两者通过同一个 `umo` 协作即可，生活数据本身就存在 `life.json` 里。

## 常见问题

**时间线里出现"和用户聊天"？**
提示词里已经明确禁止，但如果模型仍然这么写，把 `persona` 里加上"你的生活里没有用户"这类约束会更稳。

**注入后回复变慢/变贵？**
`inject_mode` 改 `low` 并调大 `inject_gap_minutes`，或者直接 `off`。

**素材抓不到？**
抖音/B站/网易云的公开接口偶尔会变。日志里搜 `[life_engine]` 能看到具体哪一路失败；全失败时会用内置兜底日程，不会中断。

**还是写了"那个游戏"没写名字？**
说明那天的榜单里没有对应作品。它只在素材里出现名字时才敢写具体名（这是为了防止瞎编），所以 Steam 独立游戏、冷门老番这类不在榜上的东西，仍然可能是泛指。想要具体名，可以把 `profile.json` 的 `games` / `anime` 里直接写作品名。

**搜索兜底失败会怎样？**
不会怎样。日志里会有一行 `搜索兜底放弃（ReadTimeout）`，然后照常生成。它本来就只有 8 秒预算，超时即弃、不重试，也不占重试次数。想让它更常成功，可以填一个 AnySearch Key 避开匿名限流。

**每天都写差不多的内容？**
调大 `recent_days`（最多 7），会参考更多天的记录来避开重复。注意它只能避开"已记录的作品和事件"，如果素材每天都一样，输出也会趋同。

**能和日记插件一起用吗？**
能，但它依赖特定的日记插件数据库结构（`plugin_data/memory_diary/memory.db` 里的 `sessions` 和 `buffer` 表）。没装或结构不同的情况下会自动跳过，不影响其它功能。想自己对接，改 `_write_diary()` 即可。
