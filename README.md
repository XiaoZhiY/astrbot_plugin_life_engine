# 生活引擎 · astrbot_plugin_life_engine

让 Bot 有**自己的日子**，并把这段生活低频注入对话。

每天一次模型调用：结合人设和兴趣，从真实抓来的素材（抖音热榜 / B站 / 网易云）里安排今天的计划、时间线和刷到的东西。之后全天不再调用模型——聊到相关话题时，直接把这些内容塞进 system prompt，它就有了"我刚在干嘛"。

## 特性

- **一天一次调用**：08:30 生成，之后靠注入，不额外烧 token
- **素材都是真的**：抖音热榜、B站热搜/热门、网易云热歌，模型只能按编号引用，编不出不存在的内容
- **作息约束**：时间线只落在 `wake_time` ~ `sleep_time` 之间，深夜不会冒出"正在看电影"
- **只写自己**：时间线里不出现"和用户聊天"这种自我引用
- **低频注入**：默认静默 30 分钟后的第一轮才注入一次，避免每轮都占 token
- **可写日记**：凌晨把当天的事压成一两句写进日记素材（可选，没装日记插件就跳过）
- **幂等 + 重试**：同一天只生成一次；失败按 2 / 5 / 15 分钟退避

## 安装

```bash
cd AstrBot/data/plugins
git clone https://github.com/XiaoZhiY/astrbot_plugin_life_engine.git
```

重启 AstrBot，在插件配置里填 `umo`（会话标识，形如 `qq_official:FriendMessage:DEADBEEF`；不确定就在目标会话发 `/sid`）。

### 改兴趣

第一次运行会生成 `data/plugin_data/life_engine/profile.json`，里面是它的兴趣画像：

```json
{
  "identity": "18 岁，学生，宅，话不多",
  "platforms": ["B站", "抖音", "网易云"],
  "games": ["王者荣耀", "原神", "Steam 独立游戏", "3A 单机"],
  "anime": ["日番", "国创"],
  "topics": ["猫", "生活区vlog", "美食探店", "番剧吐槽", "游戏攻略"],
  "habits": ["熬夜", "赖床", "半夜饿了找吃的"],
  "avoid": ["出门玩", "和网友私信互动", "线下活动", "见任何人"]
}
```

直接改这个文件，第二天生效。删掉它会按默认值重建。想让它更贴合你的人设，就改 `identity` 和 `topics`。

## 配置

| 配置项 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 关闭后不生成、不注入 |
| `persona` | 空 | 读不到会话人设时的备用口吻 |
| `generate_hour` / `generate_minute` | `8` / `30` | 每天几点安排今天 |
| `wake_time` / `sleep_time` | `08:30` / `00:30` | 作息，时间线只落在这个区间 |
| `events_min` / `events_max` | `4` / `6` | 时间线条数 |
| `keep_days` | `7` | `life.json` 保留几天 |
| `retry_times` | `3` | 失败重试次数 |
| `umo` | 空 | 哪个会话，**必填** |
| `inject_mode` | `low` | `off` / `low`（推荐）/ `always` |
| `inject_gap_minutes` | `30` | `low` 模式的间隔 |
| `write_to_diary` | `true` | 写进日记素材 |
| `diary_at` | `01:30` | 几点写，必须早于日记插件的整理时间 |
| `diary_sender` | `助手` | 日记里显示的发信人 |

### inject_mode 怎么选

| 模式 | 行为 | 适合 |
|---|---|---|
| `off` | 完全不注入 | 只想要生成的记录，不想影响对话 |
| `low` | 静默超过 `inject_gap_minutes` 后的第一轮注入一次 | 日常聊天，省 token |
| `always` | 每轮都注入 | 强人设场景，token 换连贯性 |

注入的内容长这样，只占几行：

```
【你最近】
今天想做：补番、打两把排位、整理桌面
刚发生：在补一部老番，第三集
心情：有点困但不想睡
刷到的：某款独立游戏上架了
```

## 工作流程

```
08:30 生成
  ├─ 并发抓素材：抖音热榜 / B站热搜 / B站热门 / 网易云热歌
  ├─ 加上兴趣画像和作息，一次模型调用
  ├─ 校验：时间必须在作息区间、条数在范围内、引用编号必须存在
  ├─ 存进 life.json（保留 keep_days 天）
  └─ 失败则用内置兜底日程

全天 注入
  └─ on_llm_request 钩子，按 inject_mode 把今天的片段拼进 system prompt

01:30 写日记
  └─ 把当天时间线压成一两句，写进日记插件的素材库
```

## 数据文件

```
AstrBot/data/plugin_data/life_engine/
├── life.json       每天的计划/时间线/刷到的东西
├── profile.json    兴趣画像（可手改）
└── state.json      生成状态，用于幂等
```

## 和"主动消息"类插件的关系

这个插件只负责**生成生活状态**，不负责发消息。想让它拿这段生活当话题主动找你，需要另外的主动消息插件；两者通过同一个 `umo` 协作即可，生活数据本身就存在 `life.json` 里。

## 常见问题

**时间线里出现"和用户聊天"？**
提示词里已经明确禁止，但如果模型仍然这么写，把 `persona` 里加上"你的生活里没有用户"这类约束会更稳。

**注入后回复变慢/变贵？**
`inject_mode` 改 `low` 并调大 `inject_gap_minutes`，或者直接 `off`。

**素材抓不到？**
抖音/B站/网易云的公开接口偶尔会变。日志里搜 `[life_engine]` 能看到具体哪一路失败；全失败时会用内置兜底日程，不会中断。

**能和日记插件一起用吗？**
能，但它依赖特定的日记插件数据库结构（`plugin_data/memory_diary/memory.db` 里的 `sessions` 和 `buffer` 表）。没装或结构不同的情况下会自动跳过，不影响其它功能。想自己对接，改 `_write_diary()` 即可。
